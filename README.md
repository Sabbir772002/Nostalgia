#  Nostalgia: A Social Media Platform for Elderly Users
Welcome to Nostalgia, the social media website dedicated to the elderly community. Our platform is designed to cater to the unique needs and interests of seniors providing a safe and enjoyable online environment.  In this project, Django is used for server-side logic and API development, MySQL for managing and storing user and media data, Django REST Framework for building RESTful APIs, Jira (Scrum) for project management, and Git and GitHub for version control.

## Feature List

1. **Sign Up:**  
   Users can create an account by providing personal details such as name, email, username, and address.

2. **Login:**  
   Two types of login systems:
   - **User Login:** Users log in with a username/email and password.
   - **Overseer Login:** Overseers (trusted relatives or caregivers) can track medication and monitor walking buddies for elderly users.

3. **Profile Edit (Add Overseer):**  
   Users can modify their profiles, including adding or deleting overseer accounts.

4. **Account Verification:**  
   Uses OCR and deep learning (DL) for verification with official ID documents like National IDs or passports.

5. **Find Friends (Early-Age Images):**  
   Uses DL to match users' current images with those from their youth to reconnect with old friends.

6. **Friend Suggestion:**  
   Uses machine learning (ML) algorithms to suggest friends with shared interests based on user behavior and preferences.

7. **Make Friends:**  
   Users can add others as friends or acquaintances, with the option to unfriend while maintaining a connection.

8. **Blogs:**  
   Users can share life experiences and advice through blogs, with personalized recommendations and prioritization of posts from friends.

9. **Interest-Based Groups:**  
   Users can join or create groups based on interests, promoting discussions and activities using ML algorithms.

10. **Medication Alerts:**  
    Reminders to take medication, with options to add notes and mark medication as taken.

11. **Caregiver Information:**  
    Provides access to trustworthy caregivers and healthcare professionals.

12. **Find Walking Buddy:**  
    Helps users find walking companions based on shared fitness goals, with scheduling and privacy controls.

13. **Plan a Trip:**  
    Allows users to plan trips with like-minded individuals for social and recreational purposes.

14. **Plan Events:**  
    Users can suggest and organize intergenerational events, encouraging community engagement and knowledge sharing.
