#  Nostalgia: A Social Media Platform for Elderly Users
Welcome to Nostalgia, the social media website dedicated to the elderly community. Our platform is designed to cater to the unique needs and interests of seniors providing a safe and enjoyable online environment.  In this project, Django is used for server-side logic and API development, MySQL for managing and storing user and media data, Django REST Framework for building RESTful APIs, Jira (Scrum) for project management, and Git and GitHub for version control.
